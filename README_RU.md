# SmartReplyAssistant — веб-версия для iPhone

Мобильный прототип помощника для подготовки ответов родителям. Работает в Safari и поддерживает добавление на экран «Домой».

## Что уже есть
- мобильный интерфейс;
- поле для вставки истории переписки;
- простое локальное распознавание возраста, направления и филиала по ключевым словам;
- четыре стартовых блока и возможность добавлять, редактировать и удалять блоки;
- редактируемый черновик и копирование ответа;
- локальное сохранение в браузере;
- экспорт и импорт базы знаний JSON;
- PWA-кэш для повторного открытия после загрузки.

## Важные ограничения
Это первая автономная версия без подключённой ИИ-модели. Анализ выполняется простыми правилами в браузере и может ошибаться; это не полноценное понимание переписки. Проверяй каждый черновик перед отправкой. Приложение не отправляет сообщения автоматически. Не вставляй конфиденциальные данные, если не готов хранить их в браузере устройства.

## Как установить на iPhone
Веб-приложение должно быть опубликовано по HTTPS-адресу. Открытие локального HTML-файла не даёт полноценной установки PWA.

Простой способ опубликовать:
1. Создай аккаунт на GitHub и новый репозиторий, например `smartreply-iphone`.
2. Загрузи в корень репозитория файлы из этой папки.
3. Открой Settings → Pages, выбери публикацию из ветки `main`, папка `/ (root)`, сохрани.
4. После публикации GitHub покажет HTTPS-ссылку вида `https://USERNAME.github.io/smartreply-iphone/`.
5. Открой ссылку в Safari на iPhone → кнопка «Поделиться» → «На экран Домой» → «Добавить».

Альтернатива — любой статический HTTPS-хостинг. Для PWA service worker работает только по HTTPS (кроме localhost).

## Локальная проверка на компьютере
Открой `index.html` в браузере для проверки интерфейса. Для проверки PWA и service worker используй HTTPS-хостинг или локальный сервер.

## Данные
База знаний и переписка хранятся в `localStorage` браузера и не синхронизируются автоматически между устройствами. Для переноса используй экспорт/импорт базы знаний; текущая переписка в экспорт не включается.
